# Portafolio Personal — Debora Bermeo

Este es mi sitio web de portafolio, hecho como proyecto académico. En él muestro quién soy, mis habilidades y los proyectos que he desarrollado durante la carrera, además de un formulario para que me puedan contactar.

## ¿Qué incluye el sitio?

- **Inicio:** presentación personal.
- **Sobre mí:** un poco más sobre mi perfil.
- **Habilidades:** las tecnologías que manejo y en qué nivel.
- **Proyectos:** tarjetas con los proyectos que he hecho, con opción de filtrarlos por tecnología y ver más detalles de cada uno.
- **Design System:** una muestra de los colores, letras y estilos que usé en todo el sitio.
- **Contacto:** un formulario para escribirme (de momento es solo una demostración, no envía correos reales).

También tiene modo claro y modo oscuro, un menú adaptado para celular, y un botón para volver arriba de la página.

## Con qué está hecho

- **HTML** — para el contenido y la estructura de la página.
- **CSS** — para los estilos, colores y que se vea bien en cualquier pantalla (celular, tablet, computador).
- **JavaScript** — para que la página sea interactiva (el menú, el modo oscuro, los filtros, el formulario, etc.).

No necesita instalar nada ni usar programas especiales, funciona directo en el navegador.

## Archivos del proyecto

```
├── index.html      → el contenido de la página
├── style.css       → los estilos generales
├── customer.css    → colores y tipografía
├── script.js       → la parte interactiva
├── img             → contiene las imagenes
└── README.md       → este archivo
```

## Cómo ver el proyecto

**La forma más fácil:**
1. Descarga o clona este repositorio.
2. Busca el archivo `index.html` y haz doble clic para abrirlo. Se abrirá en tu navegador (Chrome, Firefox, etc.).

**Si lo clonas desde GitHub:**
```bash
git clone https://github.com/DeboraBermeo/Portafolio.git
```
Luego entra a la carpeta descargada y abre `index.html` como se indicó arriba.
